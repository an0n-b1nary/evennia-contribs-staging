Some games let anyone create an account. Others ask you to apply first, and staff read each application before the account exists. This page covers games that review applications.

- `+apply` starts an application. You use it while visiting as a guest.
- `+referral` gives you a code to invite a friend, and `+referral/list` shows the codes you have out.
- `+request` reaches staff at any time, as [[requests]] explains.

## Applying

Connect as a guest, then use `+apply`. It asks for the account name you'd like, a password, a referral code if the game uses them, and then the game's own questions. When you're done you get an application number.

To check on it, connect with the name and password you chose. While the application is waiting, that shows its status instead of logging you in. Once staff approve it, the same name and password log you in as normal.

If an application is declined, or nobody decides it before it lapses, the name and password stop working and the name is free again. Staff may share their reason with you; otherwise it stays private. You can apply again later.

:::insight[Your password never enters the application]
The password is scrambled the moment you type it and kept apart from your answers. Staff reviewing your application never see it, and nor does anyone else.
:::

## Referrals

If the game uses referrals, an existing player can invite you with a code from `+referral`. Each code works once and expires if it isn't used. Some games require a code to apply, some make it optional, and some don't use them at all.

Each account can have only so many invitations out in a period, shared across all of its characters. An invitation that's declined or lapses is given back.

## If staff restrict an account

Restrictions apply to the whole account, so every character on it is affected.

- **A mute** stops you paging other players, talking on channels, posting to boards and talking in OOC rooms. You can still roleplay in character, use `+request`, and page staff. The game tells you when the mute ends.
- **A ban** stops you connecting until it ends or staff lift it.

Either way, `+request` or paging staff is how to ask about it.

:::insight[A way back to staff]
A mute never cuts you off from staff. However a problem started, you can always ask about it.
:::

## What staff can see

Staff see your application's answers, the account name you chose, who referred you, and checks such as whether your address matches an earlier ban or application. Those checks are only advice to the reviewer; nothing is declined automatically. Staff never see your password.

Staff can keep private notes on an account, and they can see which characters share an account. Other players can't: your characters aren't linked to each other anywhere players can see.
